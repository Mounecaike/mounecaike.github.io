L'application dédiée aux collectionneurs de figurines

Une webapp moderne construite avec Django et DRF, pensée pour gérer, organiser et partager ses figurines.

Voir le code (GitHub)

Présentation

FYGZ est une application web permettant aux collectionneurs de figurines de gérer leur collection, suivre leurs achats, partager leur profil et accéder à des fonctionnalités premium basées sur des APIs externes.

Objectifs de l'application

  • Centraliser et organiser sa collection
  • Ajouter facilement une figurine (nom, univers, prix, photo…)
  • Trier et filtrer sa collection (univers, prix, rareté…)
  • Partager son profil en ligne
  • Bonus premium : estimation automatique via l'API eBay
  • Modération automatique des images (sécurité des uploads)

Stack Technique

  • Backend : Python, Django, Django REST Framework
  • Base de données : SQLite (dev), PostgreSQL (prod)
  • Frontend : HTML, CSS, JavaScript (puis migration prévue vers React)
  • Fonctionnalités avancées : Auth, dashboard, filtres DRF, upload sécurisé
  • Déploiement : Render (à venir)
