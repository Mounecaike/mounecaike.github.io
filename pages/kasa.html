Projet Kasa

Présentation du projet

Kasa est une plateforme de location d'appartements permettant aux utilisateurs de trouver des logements adaptés à leurs besoins. Voici une vue d'ensemble du projet.

Fonctionnalités principales

Le projet comprend une recherche dynamique, des filtres avancés, et une interface utilisateur intuitive pour une expérience optimale.

Technologies utilisées

Kasa a été développé avec React pour le front-end, Node.js pour le back-end, et MongoDB pour la gestion des données.
