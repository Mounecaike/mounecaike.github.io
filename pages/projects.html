📘 Pipeline ETL – Books to Scrape

Développement d’un pipeline ETL complet appliqué au site “Books to Scrape”. Extraction, transformation, nettoyage des données, CSV automatiques et téléchargement d’images.

Fonctionnalités principales

  • Scraping multi-catégories et multi-pages
  • Pipeline complet : Extraction → Transformation → Chargement
  • Export CSV automatique
  • Téléchargement d’images
  • Architecture modulaire conforme PEP8

Technos : Python, Requests, BeautifulSoup, CSV, OS

♟️ Gestionnaire de Tournoi d'Échecs – MVC

Application Python en architecture MVC permettant de gérer des tournois d’échecs depuis le terminal. Le programme gère les joueurs, les rondes, les matchs, les résultats et sauvegarde toutes les données en JSON.

Fonctionnalités principales

  • Architecture MVC complète
  • Ajout, classement et mise à jour des joueurs
  • Gestion d'un tournoi : rondes, matchs, résultats
  • Sauvegarde persistante en JSON
  • Menus interactifs en console
  • POO propre et structurée

Technos : Python, JSON, Programmation orientée objet, MVC

Lien GitHub : Projet Tournoi d'Échecs
