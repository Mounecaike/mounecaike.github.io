# 🔥 Projet Principal : FYGZ – My Collection

> **Application web pensée pour gérer, organiser et partager sa collection de figurines.**

🎯 **Objectif du projet**  
Créer un outil moderne permettant :  
- d’ajouter des figurines (nom, univers, prix, photos…)  
- de filtrer, trier et rechercher sa collection  
- de partager son profil  
- d’accéder à des fonctionnalités premium (estimation de prix via API eBay)  
- d’assurer la sécurité des images uploadées (modération automatique)

🧱 **Technos & Architecture**
- Python, Django, DRF  
- SQLite (dev), PostgreSQL (prod)  
- HTML / CSS / JavaScript (frontend actuel)  
- Séparation claire du MVT  
- Gestion des routes API  
- Dashboard avec **OrderingFilter**, **SearchFilter**, **DjangoFilterBackend**
